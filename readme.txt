A simple WooCommerce plugin for changing simple product prices in bulk.

== Description ==

A2Z Bulk Price Changer Free is a simple WooCommerce plugin designed to make bulk product price management faster and easier.

It provides a dedicated admin interface where WooCommerce store owners can filter products and apply price changes to multiple products at once.

The Free version focuses specifically on bulk price editing and supports **simple products only**. Variable products are not supported.

Products can be filtered by category, stock status, and product status before selecting products for a bulk price change.

For pricing rules, the Free version provides a straightforward fixed-amount adjustment. Users can choose whether to increase or decrease the selected products' prices by a specified fixed amount.

The plugin is designed with simplicity in mind and focuses on making common WooCommerce bulk pricing tasks easier to manage from a single admin interface.

== Features ==

* View WooCommerce simple products from a dedicated admin interface.
* Filter products by category.
* Filter products by stock status.
* Filter products by product status.
* Select multiple products for bulk price editing.
* Increase product prices by a fixed amount.
* Decrease product prices by a fixed amount.
* Apply bulk price changes to selected products.
* Supports simple products only.
* Manage product pricing from a dedicated WooCommerce admin interface.
* Designed specifically for WooCommerce bulk price management.

== Installation ==

1. Download the plugin.
2. Upload the `a2z-bulk-price-changer` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the `Plugins` menu in WordPress.
4. Make sure WooCommerce is installed and activated.
5. Open A2Z Bulk Price Changer from the WooCommerce admin menu.

== Usage ==

After activating the plugin:

1. Open A2Z Bulk Price Changer from the WooCommerce admin menu.
2. Use the available filters to narrow down the products you want to edit.
3. Filter products by category, stock status, and/or product status.
4. Select the simple products you want to update.
5. Choose the price type you want to change.
6. Choose whether to increase or decrease the price.
7. Enter the fixed amount for the price adjustment.
8. Apply the bulk price change to the selected products.

The Free version supports simple products only. Variable products are not supported.

Always review the selected products, price type, adjustment direction, and fixed amount before applying a bulk price change.
